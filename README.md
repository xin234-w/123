## 2. 聚类分析方法分类与对比

### 2.1 主要聚类方法

| 方法类型 | 代表算法 | 簇形状 | 需预设K | 对噪声 | 复杂度 | 适用场景 |
|---------|---------|--------|--------|--------|--------|---------|
| **划分式** | K-Means、K-Medoids | 球形 | 是 | 敏感 | 低 | 大规模数据、球形分布 |
| **层次式** | 凝聚式、分裂式 | 任意 | 否 | 不敏感 | 高 | 层级结构、K值不确定 |
| **密度式** | DBSCAN、OPTICS | 任意 | 否 | 不敏感 | 中 | 非球形簇、含噪声数据 |
| **模型式** | GMM、SOM | 椭圆形 | 是 | 较鲁棒 | 中 | 概率输出、软聚类 |

### 2.2 选择建议

- **数据量大、分布均匀** → K-Means
- **数据有噪声、形状不规则** → DBSCAN
- **需要发现层级结构** → 层次聚类
- **需要概率输出** → GMM
- **需要可视化** → SOM

### 2.3 K-Means vs DBSCAN 对比

| 维度 | K-Means | DBSCAN |
|------|---------|--------|
| 簇形状 | 球形 | 任意形状 |
| 需要预设K值 | ✓ | ✗ |
| 对噪声敏感 | 是 | 否 |
| 可发现异常点 | ✗ | ✓ |
| 计算效率 | 高 | 中 |

## 3. K-Means算法流程与要点

### 3.1 算法流程图

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  初始化  │───▶│ 分配样本 │───▶│ 更新质心 │───▶│ 迭代收敛 │───▶│ 输出结果 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
   随机选择      计算距离      重新计算      重复步骤      K个簇
   K个质心      到最近质心     簇的均值      至质心不变     及其质心
```

### 3.2 核心公式

**距离度量**（最常用：欧氏距离）：
```
d(x,y) = √(Σ(xi-yi)²)
```

**质心更新**：
```
新质心 = 该簇所有样本的均值向量
```

**时间复杂度**：O(n · k · t)
- n = 样本数
- k = 簇数
- t = 迭代次数

### 3.3 四大重点关注事项

#### ① K值选择

| 方法 | 说明 |
|------|------|
| **肘部法则** | 绘制SSE曲线，选择拐点处的K值 |
| **轮廓系数** | 轮廓系数越高，簇内越紧密、簇间越分离 |
| **业务解释性** | 结合业务实际选择有意义的K值 |

#### ② 初始质心选择

| 方法 | 优缺点 |
|------|--------|
| 随机初始化 | 简单，但可能陷入局部最优 |
| **K-Means++（推荐）** | 初始化更均匀，效果更好 |
| 多次运行取最优 | 增加计算量，但结果更稳定 |

#### ③ 数据标准化

⚠️ **必须进行标准化处理！** 原因：不同特征的量纲和数值范围差异大

| 方法 | 说明 |
|------|------|
| **Z-Score标准化** | 均值为0，标准差为1（最常用） |
| Min-Max归一化 | 将数据缩放到[0,1] |

#### ④ 异常值处理

⚠️ K-Means对异常值敏感！

| 处理方法 |
|---------|
| 先用DBSCAN检测并去除异常值 |
| 使用K-Medoids代替K-Means |
| 对特征进行缩放处理 |

### 3.4 常见问题及解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 局部最优 | 随机初始化不当 | 使用K-Means++初始化，多次运行 |
| 空簇 | 某个初始质心远离数据 | 使用K-Means++；重新选择质心 |
| 簇大小不均 | 数据分布不均 | 检查数据；考虑其他算法 |
| 收敛慢 | 数据维度高或量大 | 减少特征维度；增加迭代次数 |

### 3.5 Python实现示例

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score

# 1. 数据标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(data)

# 2. 确定最优K值
inertias = []
silhouettes = []
K_range = range(2, 11)
for k in K_range:
    kmeans = KMeans(n_clusters=k, init='k-means++', random_state=42)
    kmeans.fit(X_scaled)
    inertias.append(kmeans.inertia_)
    silhouettes.append(silhouette_score(X_scaled, kmeans.labels_))

# 3. 选择最优K值后建模
best_k = silhouettes.index(max(silhouettes)) + 2
kmeans = KMeans(n_clusters=best_k, init='k-means++', n_init=10, random_state=42)
labels = kmeans.fit_predict(X_scaled)

# 4. 获取质心和簇标签
centers = kmeans.cluster_centers_
```
